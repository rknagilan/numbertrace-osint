# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, welcome beginners, give constructive feedback, and never
use the project or its community to harass anyone. This includes posting anyone's phone number
or personal details in issues.

Report problems privately to the maintainers (via a GitHub security advisory or the email listed
on the maintainer's profile). Maintainers may remove content and block participants who break these rules.
